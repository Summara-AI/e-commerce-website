# SECTION 1 — Project Overview

## 1.1 Purpose of this document

This guide tells you **exactly** what Korean Skin Lab must provide so we can:

- Replace every placeholder with final brand media  
- Populate Shopify with correct product and collection data  
- Publish accurate policies, SEO, and contact details

After a complete delivery, **no further visual or content requests should be required** for launch.

## 1.6 Naming convention (required)

```
[area]_[subject]_[descriptor]_[WxH].[ext]
```

**Examples**

| Correct | Incorrect |
|---------|-----------|
| `brand_logo_primary.svg` | `final logo NEW (2).png` |
| `product_haruharu-sunscreen_main_1600x2000.webp` | `IMG_4521.JPG` |
| `collection_best-sellers_hero_2400x1028.webp` | `banner copy.jpg` |
| `ugc_morning-routine_01_1080x1920.mp4` | `WhatsApp Video 2026.mp4` |

**Rules**

- Lowercase letters, numbers, hyphens only  
- No spaces, no emoji, no version clutter in the filename  
- Product files must include the **Shopify handle** (URL slug) when known  
- Keep a `MANIFEST.xlsx` listing every file with status (Ready / Pending / N/A)

| Item | Specification |

## 5.2 Global product photography standards

| Rule | Requirement |
|------|-------------|
| Colour accuracy | Match real packaging; soft proof against Brand Kit pinks — no teal/orange Instagram filters |
| Margin | 8–12% empty space around product on packshots |
| Angle | Front ¾ preferred; keep consistent across the catalogue for grid rhythm |

| Colour profile | sRGB |
| Naming | `product_{handle}_{shot}_{WxH}.webp` |

| Spec | Requirement |
|------|-------------|

| Aspect | **9:16** |
| Resolution | **1080×1920** minimum (4K vertical accepted) |
| Length | **15–60 seconds** (sweet spot 20–35s) |
| Format | **MP4 (H.264)** preferred; MOV accepted for masters |
| Audio | Clear voice or soft music; no copyrighted tracks without license |
| Lighting | Natural / soft daylight preferred |
| Editing | Light only — cuts OK; **no heavy filters, no beauty smoothing** |
| Framing | Subject + product readable on a small floating card |
