## Guidelines for final assets

- Soft natural light, Korean skincare aesthetic — calm, not clinical
- Prefer pearl/canvas backgrounds or soft lifestyle vignettes
- Packshots centered with 8–12% breathing room
- Preserve WCAG contrast when text overlays imagery; set `imageTone` on dark photos
- Deliver WebP/AVIF-ready masters; Next Image will optimize
- Never bake UI copy into photography
