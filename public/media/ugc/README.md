# UGC video assets

Place the final customer story video here:

- `customer-routine.mp4` (required) — portrait ~9:16, muted-friendly, under ~8MB recommended
- `customer-routine.webm` (optional)
- Poster image: set `posterSrc` in `src/content/ugc-widget.ts`

Until the file exists, the floating widget shows a premium animated placeholder and still supports expand / minimize / dismiss.
